# Domain Docs

## Layout: single-context

One `CONTEXT.md` at the repo root defines WREN's canonical vocabulary — domain terms, creative principles, session formats, and memory schema.

Architectural decisions live in `docs/adr/` as they accumulate.

## For skills that read domain context

- **Primary context**: `CONTEXT.md` (repo root)
- **ADRs**: `docs/adr/` (empty until decisions are recorded)
- **Roadmap**: `docs/roadmap.md`
