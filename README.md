## Getting Started

Wren runs as the Hermes profile `wren` with this repository as its working directory.

```bash
hermes -p wren skills trust ~/projects/agents/wren
cd ~/projects/agents/wren
hermes -p wren
```

The repository-owned skills in `.agents/skills/` load only after the repository is trusted. Wren's runtime identity remains the profile's generated `SOUL.md`; `AGENTS.md` supplies project-specific creative guidance.
